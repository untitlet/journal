# Модуль «Журнал согласий 152-ФЗ / GDPR» (untitlet.journal)

## Описание

Модуль **untitlet.journal** предназначен для фиксации, версионирования, фильтрации, экспорта и регламентного удаления юридически значимых логов получения и отзыва согласий на обработку персональных данных.

### Соответствие требованиям

- **152-ФЗ (Россия)**: статьи 6, 9, 18 — доказательная база получения согласия
- **GDPR (ЕС)**: статьи 7, 30 — условия согласия и учёт обработки
- **Рекомендации Роскомнадзора** по формированию доказательной базы

---

## Возможности

✅ **Логирование согласий** — фиксация всех метаданных (IP, User-Agent, URL, сессия, версия текста)  
✅ **Версионирование текстов** — привязка каждой записи к конкретной версии текста согласия  
✅ **Экспорт для проверок** — выгрузка в CSV с криптографическим хэшем (SHA-256)  
✅ **Автоочистка** — удаление записей по истечении настраиваемого срока (3/5/10 лет)  
✅ **Анонимизация IP** — маскирование IP через N дней после получения согласия  
✅ **Интеграция** — готовый PHP API и JS-хуки для подключения к любым формам  
✅ **Неизменяемость** — запрет на редактирование записей на уровне ORM  
✅ **Аудит** — логирование всех попыток изменения и удаления записей

## Установка

### Требования

- **Bitrix**: 20.0.0+
- **PHP**: 8.0+
- **СУБД**: MySQL 5.7+ / PostgreSQL 9.4+
- **Расширения**: mbstring, json, openssl

### Пошаговая установка

1. Скопируйте файлы модуля в директорию:
   ```
   /bitrix/modules/untitlet.journal/
   ```

2. В административной панели перейдите:
   ```
   Настройки → Настройки продукта → Модули
   ```

3. Найдите модуль **«Журнал согласий 152-ФЗ/GDPR (untitlet.journal)»** и нажмите **«Установить»**.

4. После установки модуль автоматически:
   - Создаст таблицы в БД
   - Зарегистрирует обработчики событий
   - Добавит пункт меню **«Журнал согласий»**

## Использование

### PHP API

#### Логирование согласия

```php
use Untitlet\Journal\Logger;

// Базовое использование
Logger::log([
    'user_id'       => $USER->GetID(),      // ID пользователя (null для гостей)
    'consent_code'  => 'privacy_policy',    // Код типа согласия
    'form_id'       => 'main_feedback',     // Идентификатор формы
    'consent_type'  => 'form_checkbox',     // Тип: banner, form_checkbox, profile_update, api
    'meta'          => ['campaign' => 'spring2026']  // Дополнительные метаданные
]);
```

#### Отзыв согласия

```php
// Отзыв конкретного типа согласия
Logger::withdraw([
    'user_id'       => $userId,
    'consent_code'  => 'marketing',
    'form_id'       => 'unsubscribe_form'
]);

// Полный отзыв всех согласий (GDPR Art. 17)
Logger::withdrawAll($userId, 'Запрос на удаление аккаунта');
```

#### Создание версии текста согласия

```php
use Untitlet\Journal\ORM\TextVersionTable;

// Создание новой версии (автоматически деактивирует предыдущую)
$versionId = TextVersionTable::createVersion(
    'privacy_policy',           // Код типа согласия
    '<p>Текст политики...</p>', // HTML версия
    'Текст политики...'         // Plain text версия (опционально)
);
```

### JavaScript интеграция

#### Кастомные баннеры cookie

```javascript
// После принятия пользователем условий
BX.onCustomEvent('untitlet:consent:accepted', [{
    consent_code: 'cookies',
    form_id: 'cookie_banner_v2',
    consent_type: 'banner',
    meta: { banner_version: '2.1' }
}]);

// Для отзыва согласия
BX.onCustomEvent('untitlet:consent:withdrawn', [{
    consent_code: 'cookies',
    form_id: 'cookie_settings'
}]);
```

#### AJAX-обработчик

```javascript
// Отправка данных на сервер
fetch('/bitrix/components/untitled/consent.logger/ajax.php', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'X-Bitrix-Sessid': BX.bitrix_sessid()
    },
    body: JSON.stringify({
        consent_code: 'marketing',
        form_id: 'newsletter_popup',
        consent_type: 'banner'
    })
});
```

## Автоматическое логирование

Модуль автоматически перехватывает следующие события Bitrix:

| Событие | Описание |
|---------|----------|
| `OnBeforeFormSubmit` | Отправка веб-форм (при наличии чекбокса согласия) |
| `OnAfterUserRegister` | Регистрация нового пользователя |
| `OnUserAuthorize` | Вход пользователя (опционально, требуется настройка) |

### Настройка автоматического логирования форм

Для автоматического распознавания чекбоксов согласия в формах добавьте поле с одним из имён:
- `consent`
- `privacy`
- `gdpr`
- `personal_data`
- `marketing`

Значение поля должно быть `'Y'`.

### Меню модуля

Путь: **Настройки → Журнал согласий**

#### Вкладки:

1. **Записи журнала**

3. **Экспорт** *(требуется реализация)*
   - История выгрузок
   - Скачивание файлов
   - Проверка хэш-суммы

4. **Настройки**
   - Срок хранения записей (лет)
   - Анонимизация IP (через сколько дней)
   - Включение/отключение логирования
   - Email для уведомлений об очистке

## Настройка автоочистки (Cron)

### Вариант 1: Cron-скрипт (рекомендуется)

Добавьте в crontab:

```bash
# Запуск ежедневно в 02:00
0 2 * * * /usr/bin/php /path/to/bitrix/modules/untitlet.journal/cron/cleanup.php >> /var/log/untitlet_journal_cleanup.log 2>&1
```

### Вариант 2: Агент Bitrix

При установке модуля автоматически создаётся агент, который запускается при каждом посещении сайта (не рекомендуется для высоконагруженных проектов).

## Безопасность

### Неизменяемость записей

- Записи лога доступны только для чтения (INSERT only)
- Попытки обновления блокируются на уровне ORM
- Все попытки изменения логируются в `b_event_log`

### Права доступа

| Группа прав | Описание |
|-------------|----------|
| **D** (Deny) | Доступ запрещён |
| **K** (Read) | Чтение записей, экспорт |
| **W** (Write) | Полный доступ, включая удаление |

### Анонимизация IP

Через настраиваемое количество дней IP-адреса маскируются:
```
192.168.1.100 → XXX.XXX.XXX.100
```

## Экспорт данных

### CSV-экспорт

Формат:
- Кодировка: UTF-8 с BOM (корректно открывается в Excel)
- Разделитель: точка с запятой (`;`)
- Экранирование: стандартное RFC 4180

Поля экспорта:
```
ID;Date;User ID;Session ID;IP;Consent Type;Status;Form ID;Page URL;Version;User Agent;Meta
```

### Генерация хэш-суммы

Для каждого экспорта вычисляется SHA-256 хэш:
```php
$hash = hash('sha256', $fileContent . $metadataJson);
```

Хэш сохраняется в таблице `b_untitlet_journal_export` и отображается в интерфейсе.

## Проверка соответствия 152-ФЗ / GDPR

### Чек-лист для аудита

- [ ] Модуль установлен и активен
- [ ] Все формы содержат чекбоксы согласия
- [ ] Тексты согласий загружены и имеют активные версии
- [ ] Срок хранения настроен согласно политике компании (3/5/10 лет)
- [ ] Автоочистка работает (проверить `b_event_log` на наличие `UNTITLET_JOURNAL_CLEANUP`)
- [ ] Экспорт формируется корректно (открыть в Excel, проверить кодировку)
- [ ] Права доступа настроены (только администраторы имеют доступ)
- [ ] IP-адреса анонимизируются согласно настройкам

## Устранение неполадок

### Ошибки логирования

Логи ошибок записываются в:
```
/upload/untitlet_journal_errors.log
```

### Ошибки cron

Логи cron-скрипта:
```
/upload/untitlet_journal_cron_errors.log
```

### Модуль не создаёт записи

Проверьте:
1. Модуль установлен и активен
2. В настройках включено логирование (`enable_logging = Y`)
3. Для типа согласия существует активная версия текста
4. У пользователя есть права на запись в БД

## Обновление

При выходе новых версий:

1. Сделайте резервную копию БД и файлов
2. Замените файлы модуля на новые
3. В админке перейдите в **Настройки → Модули**
4. Нажмите **«Обновить»** рядом с модулем

## Удаление

1. В админке: **Настройки → Модули**
2. Найдите **untitlet.journal**
3. Нажмите **«Удалить»**

⚠️ **Внимание**: При удалении все таблицы и данные будут безвозвратно удалены!
